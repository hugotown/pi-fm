# Ahoy

1. Recap from this session's history since the captain's last real message: what landed, what failed, what changed in the plan. Three to eight lines.
2. If there is no earlier captain message in this session, give `/skill:pifm-bearings` instead.
3. Then walk `pifm holds` one at a time: present one decision, wait for the answer, record it with `pifm answer`, relay it, and only then present the next.
